# iCreate app icon

The **Slate** launcher tile: cool slate field, ivory geometric **i** monogram, cyan accent
(`#1EC8D9`) and the family underline bar. Masters live in `docs/brand/` (monogram) and
`branding/icon-system-2026/masters/icreate.svg` (full tile).

Not an ArtCraft mark. No leaping figure, kitsune or Craft animal icons.

## Files

- `icreate.svg` / `icreate-1024.png`: full app tile
- `icreate.icns`, `icreate.ico`: macOS / Windows installers
- `hicolor/<size>/apps/za.co.icreativate.icreate.png` (16–512) and scalable SVG
- Tray: `docs/brand/icreate-mark-black-44.png` (macOS template) and `icreate-mark-64.png` (colour)

## Regenerate

From the suite masters (after editing `branding/icon-system-2026/`): re-run the apply script
or `packaging/icons.sh` once it points at the Slate masters.
